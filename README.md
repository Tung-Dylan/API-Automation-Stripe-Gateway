# API-Automation-Stripe-Gateway
Lộ trình thực hiện :
  Bước 1: Thiết lập môi trường, JDK và Maven trong IDE Inteliji.
  Bước 2: Tạo project Maven.
  Bước 3: Cấu hình thư viện trong pom.xml gồm Java, REST Assured, TestNG và các thư viện cần thiết.
  Bước 4: Tạo cấu trúc thư mục : config - models - utils - tests
  Bước 5: Viết cấu hình Stripe gồm base URL và quản lý Key API an toàn.
  Bước 6: Viết test API gửi request và kiểm tra response
  Bước 7: Các nhóm test nghiệp vụ, báo cáo và CI.
